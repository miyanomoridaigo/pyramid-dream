⚙ Firebase 設定

Firebase Firestore で夢のデータを保存・同期します。
Firebase Console でプロジェクトを作成し、 プロジェクト設定 → 全般 → ウェブアプリ から取得した設定値を貼り付けてください。

初回セットアップ手順を表示
  1. Firebase Console でプロジェクト作成
  2. 左メニュー「Firestore Database」→「データベースを作成」（テストモードでもOK）
  3. プロジェクト設定 → ウェブアプリを追加 → 設定値をコピー
  4. 下のフォームに貼り付けて保存
  5. Firestoreのセキュリティルールは利用形態に合わせて設定してください
